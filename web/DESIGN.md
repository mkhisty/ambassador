# Ambassador workspace

Mode: Operate. Design supports an organizer reviewing sponsorship progress and deciding the next action.

Use a warm white content surface, quiet neutral navigation, dark text, and one forest-green action color. Use a single system sans family. Labels are readable at ordinary desktop and mobile sizes; numeric columns use tabular figures. Separate sections with spacing and fine rules rather than repetitive tinted cards.

The Sankey follows the organizer's reference: three columns, broad neutral bands, square vertical nodes, directly attached labels. Inputs represent actual outreach channels; output branches represent actual current sponsor stages. Committed is green and declined is muted terracotta. Band widths represent sponsor counts. This is a current distribution, not a conversion-history claim. Full historical changes remain in each sponsor's activity timeline.

Avoid promotional slogans, eyebrows, redundant counts, decorative icon tiles, gradients, fake avatars, and repeated connection notices. Keep native form controls, visible focus, descriptive empty states, clear primary actions, and responsive layouts.

Guidance: Impeccable's official distill, Operate, and craft-floor references, read from the upstream repository. The Impeccable executable is not installed in this workspace.
